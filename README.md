# Personal research website

Live at: https://YOUR_USERNAME.github.io

## Publish (5 minutes)
1. On GitHub, create a **public** repository named exactly `YOUR_USERNAME.github.io`.
2. Upload `index.html` and this `README.md` (Add file → Upload files → Commit).
3. Also upload `profile.jpg` (square photo) and `cv.pdf` to the repo root.
4. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
5. Wait ~1 minute, then open https://YOUR_USERNAME.github.io

## Edit content
Projects and datasets are in the `PROJECTS` and `DATASETS` lists near the bottom of `index.html`.
- Paste a URL into any link (e.g. `Code: "https://github.com/..."`) when it's ready; empty links show "Link coming soon".
- Publications are not listed on the page — it links to your Google Scholar profile instead.
- Search the file for `YOUR_`, `[LastName]` and `20XX` to find every placeholder.

## Datasets
- Small files: put them in a separate repo and use GitHub Releases for downloads.
- Large datasets: upload to **Zenodo** (free, up to 50 GB) — it gives a DOI people can cite.
  Connect Zenodo to GitHub to get a DOI for each code release too.
- Add a `CITATION.cff` file to each code repo so GitHub shows a "Cite this repository" button.
